# Homestro AI Control — Shopify Sidekick

This extension exposes Homestro product-search and price-rule tools to Shopify Sidekick.

The tools use Shopify Direct API from the Shopify sandbox, so the Sidekick extension does not need a manually copied Shopify Admin API token.

The Railway service remains the AI/middleware layer for future product-content generation, image generation, sourcing and background workflows.
